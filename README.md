# 三行日記

毎日20時にポップアップが表示され、その日の出来事を3行・200字以内で記録できる、完全ローカル動作のWindowsデスクトップツールです。

- インターネット通信は一切行いません
- 入力した内容はすべてあなたのPC内にのみ保存されます
- 月次カレンダーでこれまでの日記を振り返れます
- CSVでのデータ書き出しに対応しています

## ダウンロード

このリポジトリの [Releases](../../releases) ページから `sangyou-nikki-Setup-1.0.0.exe` をダウンロードしてください。

## インストール時の注意

インストーラーを起動すると、「インストール対象のユーザーを選択」という画面が表示されることがあります。
**「現在のユーザーのみ」を選んでください（管理者権限は不要です）。**

また、Windowsから
**「WindowsによってPCが保護されました」** という青い画面が表示されることがあります（表示されない場合もあります）。

これは故障やウイルスではなく、個人が作ったソフトウェアに共通で表示されるものです（有料の発行者証明書を取得していないため）。

続行する場合は、以下の手順で進めてください。

1. 「詳細情報」をクリック
2. 「実行」をクリック

不安な場合は、無理にインストールしないでください。

### Smart App Control をお使いの場合

Windows 11の「Smart App Control」を有効にしている場合、インストールがブロックされることがあります。

この機能がブロックした場合は、**設定を変更せず、インストールを見送ってください。** Smart App Controlは一度無効にすると再度有効化できない仕様のため、無理に解除することはおすすめしません。

## 動作環境・容量

- Windows 10 / 11
- インストール後の容量：約220MB

## 再インストール・上書きインストールについて

すでに三行日記を起動した状態で再度インストーラーを実行すると、「三行日記が終了できません」という画面が出ることがあります。

これはデータの破損とは関係ありません。事前に通知領域のアイコンを右クリックして「終了」を選んでから、インストーラーを実行すると避けられます。すでにこの画面が出た場合は、「再試行」をクリックすれば、そのまま進めます。

## データの保存場所

```
C:\Users\(ユーザー名)\AppData\Roaming\三行日記\diary.json
```

バックアップを取りたい場合は、このファイルをコピーして保管してください。
